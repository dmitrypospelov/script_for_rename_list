<h1>Что делает скрипт?</h1>
Скрипт необходим для переименования листов таблицы и создания индивидуального шаблона бюджета.
<h2>Описание работы</h2>
<h4>Нажатие с компьютера</h4>
  1. При нажатии Настроить, по стрелке desktop, появляется модальное окно для задания параметров;<br>
  2. В pop-up задаются параметры ячейки месяца в разделе Начало периода;<br>
  3. В pop-up задается Начальная сумма с проверкой на формат введения (только числа, без пробелов);<br>
  4. Далее скрипт задает файлам временные имена, нумерует их, после чего задает имена в соответствии со списком, определенным от первого месяца и года в разделе Начало периода.<br>
<h4>Нажатие с телефона или планшета</h4>
  1. Сначала задается месяц в Начале периода;<br>
  2. После нажатия чек-бокса срабатывает триггер, который запускает скрипт переименования;<br>
  3. Далее скрипт задает файлам временные имена, нумерует их, после чего задает имена в соответствии со списком, определенным от первого месяца и года в разделе Начало периода.<br>
